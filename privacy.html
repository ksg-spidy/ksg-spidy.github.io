NdisBills Privacy Policy

Last updated: 26 October 2026

NdisBills is a private tool used only by its owner to manage their own NDIS invoices. It is not available to the public.

What it accesses

  • Gmail: reads messages with invoice attachments and adds a label to processed messages.
  • Google Drive: saves invoice PDFs to a folder in the owner's Drive and updates the owner's tracking sheet.
  • Google Calendar: creates payment reminder events on the owner's calendar.

How data is used

Data is used only to file and track the owner's invoices. It is processed on the owner's own computer and stored only in the owner's own Google account. It is not sold, shared with anyone else, or used for advertising.

Google API data

NdisBills' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time from Google Account → Third-party apps.
